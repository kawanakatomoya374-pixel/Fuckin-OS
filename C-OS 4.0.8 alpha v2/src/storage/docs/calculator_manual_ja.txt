C-OS 4.0.6 電卓 かんたん説明書

1. 起動
デスクトップの「Calculator」を開くと電卓が起動します。

2. モード
Basic: ふつうの四則演算
Sci: sin / cos / tan などの関数計算
HS3: 高校数学向けの式や連立方程式
Hissan: ひっ算表示つきの学習モード

3. よく使うボタン
- 数字 0〜9
- +, -, *, /, %
- ( )
- =
- AC / C
- DEL
- M+, M-, MC, MR
- DEG / RAD

4. 例
- 1+2
- (3+4)*5
- sin(30)
- solve2(1,1,12,1,-1,1)
- quad(1,-3,-4)
- frac(1/2+1/3)

5. ひっ算
Hissan モードでは、筆算の流れを見ながら計算できます。
小数の足し算・引き算・掛け算にも対応しています。

6. こまったとき
式が長いときは、まず Basic モードで少しずつ確かめてください。
