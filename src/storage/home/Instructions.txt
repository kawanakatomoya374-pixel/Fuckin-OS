
C-OS Instructions
=================

Version: C-OS 4.x
Language: Japanese

========================================
1. 基本操作
========================================

■ マウス
- 左クリック : 選択 / 実行
- ダブルクリック : ファイル・アプリを開く
- 右クリック : コンテキストメニュー

■ ウィンドウ操作
- 最小化
- 最大化
- 閉じる
- ドラッグ移動
- ウィンドウサイズ変更

========================================
2. デスクトップ
========================================

デスクトップでは以下が可能です。

- アプリ起動
- ファイルアクセス
- アイコン選択
- 右クリックメニュー
- ファイル管理

========================================
3. ファイルマネージャー
========================================

■ 機能
- ファイル閲覧
- フォルダ移動
- テキストファイル編集
- 保存
- コピー
- 削除
- 名前変更
- 新規ファイル作成
- 新規フォルダ作成

■ テキストファイル編集
テキストファイルをダブルクリックすると
テキストエディターで開きます。

編集後は Save ボタン または Ctrl+S で保存できます。

========================================
4. テキストエディター
========================================

■ 主な機能
- テキスト編集
- 保存
- 上書き保存
- 行番号表示
- ステータスバー
- 選択操作
- コピー＆ペースト
- 検索
- 置換

■ ボタン
- New        : 新規作成
- Open       : ファイルを開く
- Reload     : 再読み込み
- Save       : 保存
- Select All : 全選択

■ ショートカットキー
- Ctrl+N : 新規作成
- Ctrl+O : 開く
- Ctrl+S : 保存
- Ctrl+A : 全選択
- Ctrl+C : コピー
- Ctrl+X : 切り取り
- Ctrl+V : 貼り付け
- Ctrl+F : 検索
- Ctrl+H : 置換

========================================
5. 計算機（Calculator）
========================================

■ 基本計算
- 足し算
- 引き算
- 掛け算
- 割り算

■ 対応例
- 12 + 8
- 100 - 25
- 5 * 9
- 144 / 12

■ 関数
- sqrt(x)   : 平方根
- pow(a,b)  : 累乗
- sin(x)
- cos(x)
- tan(x)

■ メモ
角度系は実装によってラジアン計算になる場合があります。

========================================
6. 音楽プレイヤー
========================================

■ 機能
- MP3再生
- 一時停止
- 停止
- 曲送り
- 音量変更

========================================
7. ストレージ
========================================

■ 構成
- home/
- docs/
- shared/

■ 特徴
- 仮想ファイルシステム
- FAT32ベース
- RAM filesystem 対応

========================================
8. コマンド / システム機能
========================================

■ システム機能
- GUI Desktop
- Window System
- File System
- Audio System
- Input System
- Storage Manager

========================================
9. ヒント
========================================

- 保存前に終了すると内容が失われる場合があります
- 編集後は Ctrl+S 推奨
- 大きなファイルは処理に時間がかかる場合があります

========================================
10. 更新済み機能
========================================

このバージョンでは以下を強化しています。

- テキストエディターUI改善
- ショートカットキー追加
- Save機能強化
- ファイルマネージャー連携改善
- テキストファイル直接編集対応

Enjoy C-OS!
